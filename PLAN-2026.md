# QIP 2026 Site Migration Plan

## Overview
Migrate content from qip2026.lu.lv (static copy at `../qip.iaqi.org/2026/`) to the Hugo template, following the Eurocrypt-style menu structure.

## Key Configuration
- **Theme Color**: `#004a87` (teal from source site)
- **City**: Riga, Latvia
- **Dates**: January 24-30, 2026 (Tutorials: Jan 24-25)

---

## Phase 1: Create Base Structure

### 1.1 Copy directory structure from 2024
```
cp -r content/2024 content/2026
```

### 1.2 Update `hugo.toml`
Add `[params.2026]` section:
```toml
[params.2026]
  city = "Riga, Latvia"
  timeanddate_cityid = 241  # Riga
  themeColor = "#004a87"
  [params.2026.logos]
    jumbo = "/images/2026/qip2026-home-banner.jpg"
    header = "/images/2026/qip2026-logo.png"
    banner = "/images/2026/qip2026-banner.jpg"
```

### 1.3 Create menu structure (Eurocrypt-style)
```toml
[[menu.2026]]
  name = "Home"
  weight = 10
  identifier = "home"
  pageRef = '/2026'

[[menu.2026]]
  name = "Technical Program"
  weight = 20
  identifier = "technical-program"

[[menu.2026]]
  name = "Attend"
  weight = 30
  identifier = "attend"

[[menu.2026]]
  name = "Sponsors"
  weight = 40
  identifier = "sponsors"
  pageRef = "/2026/partners"

[[menu.2026]]
  name = "Committees"
  weight = 50
  identifier = "committees"
  pageRef = "/2026/team"
```

### 1.4 Create theme file
Create `themes/devfest-theme-hugo/assets/style/theme-2026.scss`:
```scss
@use "root";
@use "variables";
@use "partials/*";
@use "pages/*";

:root {
    --primary: #004a87;
}
```
